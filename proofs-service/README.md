# Proofs Service

The Proofs Service stores, indexes, and serves proof artifacts generated by Certen validators, and provides a React-based Proof Explorer for browsing and verifying proofs.

## Components

The Proofs Service has two components:

- **Backend**: Go REST API for proof storage, retrieval, and verification
- **Frontend**: React/Vite/Ant Design proof explorer UI

## API Endpoint Reference

### Proof Queries

| Endpoint | Method | Description |
|----------|--------|-------------|
| `/api/v1/proofs` | GET | List proofs with pagination and filtering |
| `/api/v1/proofs/{id}` | GET | Get a specific proof by ID |
| `/api/v1/proofs/latest` | GET | Get the most recent proof |
| `/api/v1/proofs/by-batch/{batchId}` | GET | Get all proofs in a batch |
| `/api/v1/proofs/by-chain/{chain}` | GET | Get proofs for a specific chain |
| `/api/v1/proofs/by-adi/{adiUrl}` | GET | Get proofs related to an ADI |

### Bundle Queries

| Endpoint | Method | Description |
|----------|--------|-------------|
| `/api/v1/bundles/{batchId}` | GET | Get full proof bundle (all phases) |
| `/api/v1/bundles/latest` | GET | Get most recent bundle |
| `/api/v1/bundles/stats` | GET | Bundle statistics (count, avg size) |

### Anchor Records

| Endpoint | Method | Description |
|----------|--------|-------------|
| `/api/v1/anchors` | GET | List anchor records with filtering |
| `/api/v1/anchors/{id}` | GET | Get anchor record by ID |
| `/api/v1/anchors/by-chain/{chain}` | GET | Get anchors for a chain |
| `/api/v1/anchors/by-tx/{txHash}` | GET | Get anchor by transaction hash |

### Verification

| Endpoint | Method | Description |
|----------|--------|-------------|
| `/api/v1/verify/{batchId}` | GET | Verify a proof bundle on-chain |
| `/api/v1/verify/merkle` | POST | Verify a Merkle proof against a root |

### Intents

| Endpoint | Method | Description |
|----------|--------|-------------|
| `/api/v1/intents` | GET | List tracked intents |
| `/api/v1/intents/{id}` | GET | Get intent status |
| `/api/v1/intents/by-adi/{adiUrl}` | GET | Get intents for an ADI |

### Attestations

| Endpoint | Method | Description |
|----------|--------|-------------|
| `/api/v1/attestations` | GET | List validator attestations |
| `/api/v1/attestations/by-batch/{batchId}` | GET | Get attestations for a batch |

### System

| Endpoint | Method | Description |
|----------|--------|-------------|
| `/api/v1/health` | GET | Health check |
| `/api/v1/stats` | GET | Overall system statistics |

## Configuration

| Variable | Default | Description |
|----------|---------|-------------|
| `DATABASE_URL` | `postgres://localhost:5432/certen_proofs` | PostgreSQL connection string |
| `API_PORT` | `8080` | HTTP server port |
| `API_HOST` | `0.0.0.0` | HTTP server bind address |
| `CORS_ORIGINS` | `*` | Allowed CORS origins |
| `LOG_LEVEL` | `info` | Log verbosity |
| `MAX_PAGE_SIZE` | `100` | Maximum pagination page size |
| `RATE_LIMIT_RPM` | `300` | Rate limit (requests per minute) |
| `ETHEREUM_RPC` | (optional) | For on-chain verification calls |

## Setup

### Docker Compose (Recommended)

```bash
cd ~/certen/proofs_service
docker-compose up -d   # Starts PostgreSQL + API + Explorer
```

### Manual Setup

```bash
cd ~/certen/proofs_service

# Configure
cp .env.example .env
# Edit .env: set DATABASE_URL, API_PORT

# Database
createdb certen_proofs
go run ./cmd/migrate up

# Start API
go run ./cmd/proof-service

# Start Explorer (separate terminal)
cd frontend
npm install
npm run dev
```
